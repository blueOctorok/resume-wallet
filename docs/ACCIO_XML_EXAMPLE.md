# Accio XML Format Example

This document shows the current XML format generated by our system for MVR orders.

## Standard MVR Order (No FMCSA)

```xml
<?xml version="1.0" encoding="UTF-8"?>
<Accio_Order>
    <mode>PROD</mode>
    <login>
        <account>testaccount</account>
        <!-- ATS master account name -->
        <username>admin</username>
        <!-- ATS master user name -->
        <password>demo2023</password>
        <!-- ATS master password -->
    </login>
    <placeOrder number="1733174400001234">
        <mode>PROD</mode>
        <SuppressApplicantPortalEmail>Y</SuppressApplicantPortalEmail>
        <orderInfo>
            <requester_name use_default="Y"/>
            <requester_phone use_default="Y"/>
            <requester_fax use_default="Y"/>
            <requester_email use_default="Y"/>
            <requester_billingdata/>
            <requester_billingdata2/>
            <requester_billingdata3/>
        </orderInfo>
        <package>A LA CARTE</package>
        <subject>
            <name_first>Johnny</name_first>
            <name_middle>B</name_middle>
            <name_last>Bad</name_last>
            <name_suffix/>
            <email>driver@example.com</email>
            <ssn>6789</ssn>
            <dob>19431101</dob>
            <gender>M</gender>
            <race>U</race>
            <phone_number>555-555-5555</phone_number>
            <address>132 Any Lane</address>
            <city>Fantasy Island</city>
            <state>TX</state>
            <zip>78749</zip>
            <jobstate>NY</jobstate>
            <citizenship_status>A citizen of the United States</citizenship_status>
            <FCRAPurpose>Employment by Hire or Contract</FCRAPurpose>
            <ApplicantID/>
            <RequisitionNumber/>
            <managerName/>
            <position_requested/>
            <drugscreen>N</drugscreen>
            <has_admitted_convictions>N</has_admitted_convictions>
            <admitted_conviction_details/>
            <portalfromapplicant>Y</portalfromapplicant>
        </subject>
        <postBackInfo>
            <URL>https://yourapp.com/api/mvr/webhook</URL>
            <guID>veree-1733174400-abc123def456</guID>
            <account>testaccount</account>
            <username>admin</username>
            <postback_types>CETA::IPC::EXP::CNF::OCR::RDC</postback_types>
        </postBackInfo>
        <subOrder type='MVR'>
            <dlnum>12345678</dlnum>
            <dlstate>TX</dlstate>
            <!-- See 'State Conversion' -->
            <mvr_searchtype>standard</mvr_searchtype>
            <!-- Optional -->
        </subOrder>
    </placeOrder>
</Accio_Order>
```

## Key Differences from Old Format

### Added Fields:
1. **`<SuppressApplicantPortalEmail>Y</SuppressApplicantPortalEmail>`** - Prevents Accio from sending portal emails directly to applicants (we handle all driver communication)
2. **`<gender>M</gender>`** - Driver's gender (M/F/U)
3. **`<race>U</race>`** - Race code (defaults to U for Unknown)
4. **`<jobstate>NY</jobstate>`** - State where job will be performed (can differ from residential state)
5. **XML Comments** - Added clarifying comments matching Accio's production format

### Changed Values:
- **`<portalfromapplicant>`** changed from `N` to `Y` to match production format
- **Phone handling** - Now defaults to `555-555-5555` if not provided instead of empty tag

### Optional Enhancement:
- **FMCSA subOrder** - Can include Federal Motor Carrier Safety Administration crash/inspection report alongside MVR

## API Usage

### Simple MVR Order:
```bash
curl -X POST https://yourapp.com/api/mvr/order \
  -H "Content-Type: application/json" \
  -d '{
    "walletAddress": "0x1234...",
    "dlNumber": "12345678",
    "dlState": "TX"
  }'
```

### MVR Order with FMCSA Report:
```bash
curl -X POST https://yourapp.com/api/mvr/order \
  -H "Content-Type: application/json" \
  -d '{
    "walletAddress": "0x1234...",
    "dlNumber": "12345678",
    "dlState": "TX",
    "includeFmcsaCrashInspection": true
  }'
```

### MVR Order with Job State:
```bash
curl -X POST https://yourapp.com/api/mvr/order \
  -H "Content-Type: application/json" \
  -d '{
    "walletAddress": "0x1234...",
    "dlNumber": "12345678",
    "dlState": "TX",
    "jobState": "NY"
  }'
```

## Notes

- All personal data is extracted from the driver's completed DOT application
- SSN is limited to last 4 digits for security
- Gender defaults to 'U' (Unknown) if not in DOT application
- Job state defaults to residential state if not specified
- Phone number defaults to `555-555-5555` if not provided
- Webhook GUID is auto-generated with format: `veree-{timestamp}-{random}`
- Order number is auto-generated with format: `{timestamp}{random4digits}`
